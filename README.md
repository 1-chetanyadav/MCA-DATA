4. Semester 1 — Foundation and placement base
   
Primary objective: become independently competent in Python, DSA, SQL and basic software development.

•	Python: syntax → functions → OOP → modules/packages → exceptions → file handling → virtual environments → debugging → basic testing → type hints.

•	DSA: arrays, strings, hashing, sorting, binary search, linked lists, stacks, queues and recursion.

•	SQL: SELECT, WHERE, JOIN, GROUP BY, HAVING, subqueries, CTEs, window functions, indexes and transactions.

•	Git/GitHub: repositories, branches, commits, pull requests, merge conflicts and README writing.

•	Linux: navigation, permissions, processes, environment variables and basic shell commands.

•	Build one small project without following a tutorial.

Semester 1 deliverable

Build a Python + PostgreSQL 'Student Placement Tracker'. It should allow students to store companies, roles, eligibility, application status, assessment dates, interview rounds and preparation tasks. Expose at least five REST endpoints and write tests for them.

6. Semester 2 — Machine learning + backend
   
Primary objective: move from programming student to someone who can build a useful data/AI application.

•	NumPy + pandas + matplotlib.

•	Statistics: mean/variance, distributions, correlation, probability basics and evaluation metrics.

•	Machine learning: regression, classification, trees, ensembles, clustering, train/validation/test split, overfitting and cross-validation.

•	scikit-learn: preprocessing, pipelines, model training and evaluation.

•	Backend: FastAPI, REST, Pydantic, authentication basics and PostgreSQL.

•	Docker fundamentals: image, container, Dockerfile and docker-compose.

Semester 2 deliverable

Build an 'AI-assisted Placement Skill Analyzer'. A user uploads a resume and a job description. The system extracts skills, compares them against the job requirements, identifies gaps, and produces a preparation plan. Use a real ML model where appropriate and an LLM only where language reasoning adds value. Store users/results in PostgreSQL and expose the system through FastAPI.
